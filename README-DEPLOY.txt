How to open this site
=====================

Local (XAMPP):
  http://localhost/shakur/site/

Do NOT open index.html by double-click (file://). CSS and images will break.

Netlify:
  1. Open https://app.netlify.com/drop
  2. Drag this whole "site" folder onto the page
  3. You get a public HTTPS link

Contact form uses Netlify Forms (name="enquiry").
